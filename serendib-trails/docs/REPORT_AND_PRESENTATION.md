# Report and presentation outline (assignment aligned)

## Assignment grading
Report: 60 marks (maximum 3,000 words). Group presentation: 40 marks. Demonstrate Website → Tracking → Data collection → Analysis → Insights → Campaign.

## Report suggested structure
1. Executive summary (150 words): purpose and selected business concept (Serendib Trails, hypothetical student tourism brand).
2. Tourism website (350): target audience, pages, features, responsive design, screenshots, hosting URL.
3. Digital tracking implementation (550): GTM tag/trigger/variable inventory, GA4 Google tag and GA4 Event tags, Meta Pixel via GTM, consent, screenshots, testing outcome.
4. Data collection and visitor behavior analysis (650): analysis period, active users, total views, engagement, sessions by channel, top landing pages, events, device categories, country if available. Use *actual* GA4 reports and screenshots; do not invent values.
5. Tourism insights (350): interpret actual observed findings, e.g. which CTA/destination received strongest interest and source quality. If little real data, clearly say sample too small and explain limits.
6. Proposed campaign (550): campaign concept, goal, target market, platform, creative message, KPIs and illustrative budget below.
7. Recommendations and conclusion (250): next testing/SEO/user experience improvements.

## Campaign proposal — replace assumptions with analytics evidence
Campaign name: **Discover Your Serendib**
Objective: generate quality experience enquiries and raise destination awareness.
Target segment hypothesis: travel-curious adults aged 20–40 interested in Sri Lanka culture, nature and experiences; refine only with sufficient consented audience data.
Channels: Instagram/Reels + Facebook + organic search. Pixel can support permitted retargeting if data, permissions and audience requirements are met.
Offer: sample itinerary inspiration and a contact enquiry (not guaranteed package sales).
Message: **Go beyond the postcard. Find your wild side of Sri Lanka.**
Landing URL: /experiences.html with UTM campaign codes.
Illustrative budget (not a committed spend): LKR 30,000 total = 18,000 Instagram/Meta awareness + 9,000 engagement/traffic + 3,000 creative testing.
KPIs: engaged sessions, destination engagement events, CTA click rate, demo enquiry completion rate and cost per lead only if a real paid campaign runs and real enquiries are supported.

## Formulas
CTR = ad clicks / impressions × 100 (requires paid/social platform data).
CTA click rate = CTA clicks / landing page views × 100.
Engagement rate = engaged sessions / sessions × 100 (GA4 defined metric).
Lead conversion rate = completed enquiries / sessions × 100 (real site needs backend for genuine leads; demo form uses only an interaction event).
Cost per lead = campaign spend / genuine leads (do not treat demo enquiries as real customers).
