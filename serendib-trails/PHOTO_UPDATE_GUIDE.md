# Serendib Trails — Your Photos Update

## Steps
1. Unzip the entire project.
2. Open `index.html` in Live Server and check images.
3. When deploying, upload the WHOLE project folder including `assets/images/`.
4. If your old deployment already has a real GTM ID, copy its `assets/config.js` to this updated project before deploying.
